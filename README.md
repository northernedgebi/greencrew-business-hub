# Greencrew Business Hub

Build a complete, professional, mobile-friendly landscaping business management SaaS platform called LawnOffice.

The website will allow independent landscaping companies to create accounts, subscribe to the platform, and manage their entire business.

This must be a multi-tenant application. Each landscaping company must have its own secure workspace with completely isolated customer records, employees, scheduling, billing, and financial data.

Core modules:

Dashboard with business KPIs

Customer relationship management (CRM)

Customer properties and service locations

Employee and crew management

Job scheduling and dispatch

Recurring lawn maintenance

Estimates and proposals

Customer contracts and agreements

Invoicing and payment collection

Automatic recurring credit-card billing

Customer payment plans

Route planning

Customer communication

Customer portal

Reporting and financial analytics

Platform administrator dashboard

User roles:

Platform Super Admin

Landscaping Company Owner

Office Manager

Crew Manager

Employee / Field Technician

Customer

Each role must have appropriate permissions.

Create a modern, professional website that works equally well on desktop, tablet, and mobile devices.

The application should function like a mobile app on phones, with intuitive navigation, large touch-friendly controls, and responsive layouts.

Create a marketing homepage where landscaping companies can learn about the software, review subscription plans, register, and log in.

Do not create demonstration-only functionality. All core features must use persistent database records and working business logic.

Build the foundation first, including secure authentication, company isolation, roles, navigation, and the database structure.
